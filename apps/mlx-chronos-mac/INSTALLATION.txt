MLX Chronos for macOS — Installation and first launch

Requirements: Apple Silicon, macOS 14 or later, and a supported inference
engine. First launch needs Internet to download private Python, a verified
compatible mlx-chronos release and dependencies. Engines/model weights are
separate. After preparation the installed CLI works offline.

1. Drag MLXChronos.app onto the Applications shortcut.
2. Open MLX Chronos from Applications, not directly from this disk image.
3. Eject the disk image after installation.

This free build has a local/ad-hoc signature. It is NOT Developer ID signed
or notarized by Apple. macOS may block its first launch.

Only if you trust the official download and its integrity:
- First try opening the installed app.
- If macOS blocks it, open System Settings > Privacy & Security.
- Find the notice for MLX Chronos, choose Open Anyway, and confirm Open.

This authorizes this app; do not disable Gatekeeper globally or remove
quarantine attributes. Managed Macs may prevent manual authorization.
If macOS reports damage, a signature mismatch or malware, stop and verify
the download rather than ignoring the warning.

Verify the DMG against its matching .sha256 file from the same GitHub release.
A matching checksum detects a changed download; it does not replace Apple's
identity verification or notarization. Use only the official repository:
https://github.com/igurss/mlx-chronos/releases

Automatic setup starts at launch. In Environment, use Check / prepare compatible
CLI to retry. Existing Python installations are preserved. Start your inference
server separately. CLI updates and app download notifications are independent.
Tests configure measurements; Results inspect or explicitly share saved data.
